Passos para implementar a Home

Criar src/pages/home.tsx

Componente Home com o cabeçalho da página (título + ThemeToggle, reaproveitando o padrão visual do emails.tsx).
Seção de ação: botão "Importar planilha" (estilizado, onClick vazio/no-op por enquanto).
Seção de grid: cards de página. Por enquanto, um array estático com 1 item (ex.: "Sistema de E-mails") apontando para a rota /emails.
Cada card é um <Link> do react-router-dom (ou useNavigate), não um <button> — semântica de navegação.


Adicionar estilos no index.css

Nova seção "Home / Dashboard de planilhas" seguindo os padrões já existentes (variáveis --color-*, --radius-*, --shadow-*, --transition-*).
Classes: .home-page, .home-page-header, .home-page-acoes, .botao-importar-planilha, .grid-cards-paginas, .card-pagina, .card-pagina-icone, .card-pagina-titulo, .card-pagina-meta etc.
Estado hover/focus consistente com .counter-card e outros já existentes.
Bloco responsivo dentro do @media (max-width: 720px) já existente.


Atualizar src/App.tsx

Trocar rota / para renderizar <Home />.
Nova rota /emails (ou /emails/:id pensando no futuro) para <Emails />.
Rota * decide depois (provavelmente redirecionar para /).


Ícone para o botão de importar

Adicionar um ícone novo em Icons.tsx (ex.: FiUpload → IconeImportar), mantendo o padrão dos ícones existentes.


Dados do card (mock, preparando terreno para o futuro)

Modelar um tipo simples inline (ex.: { id, titulo, subtitulo, rota }) só com o necessário agora, sem over-engineering — já que sabemos que isso vai virar algo dinâmico (planilhas reais) depois.
